# Overview

Mosaic for Reddit is a browser extension that transforms Reddit into a fast, modern media browsing experience.

Instead of opening individual posts one by one, Mosaic displays media in a responsive masonry layout that allows you to browse continuously through images, galleries, GIFs, and videos with minimal interruptions.

Open any piece of media into an immersive viewer featuring fullscreen mode, keyboard navigation, zoom controls, slideshow support, and extensive customization options.

Everything runs locally inside your browser.

No accounts.

No cloud synchronization.

No analytics.

No tracking.

# Installation

## Google Chrome

1. Download or obtain the extension.
2. Open:

```
chrome://extensions
```

3. Enable **Developer Mode**.
4. Select **Load unpacked**.
5. Choose the Mosaic extension folder.

---

## Microsoft Edge

1. Open:

```
edge://extensions
```

2. Enable **Developer Mode**.
3. Choose **Load unpacked**.
4. Select the extension folder.
